# marco-colonna.github.io

## Getting Started

To run this site locally, ensure you have Ruby and Bundler installed, then follow these steps:

1. Clone the repository: `git clone https://github.com/marco-colonna/marco-colonna.github.io.git`
2. Install dependencies: `bundle install`
3. Start the Jekyll server: `bundle exec jekyll serve`
4. Open your browser at `http://localhost:4000`
